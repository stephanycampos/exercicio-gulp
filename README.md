# exercicio-gulp
Descrição do Projeto
Neste projeto, eu desenvolvi e configurei um arquivo Gulpfile.js com o objetivo de automatizar tarefas comuns no desenvolvimento front-end. As tarefas configuradas foram:

Compilação do SASS: criei uma task para compilar arquivos .scss em .css, facilitando o gerenciamento dos estilos do projeto.

Compressão de imagens: configurei uma task para otimizar as imagens disponibilizadas no material de apoio, reduzindo o tamanho dos arquivos sem comprometer a qualidade.

Compressão de código JavaScript: implementei uma task para minificar os arquivos JavaScript, contribuindo para melhorar a performance.

Todo o projeto, incluindo o arquivo Gulpfile.js, foi armazenado diretamente no repositório principal, e o link foi enviado conforme solicitado pela plataforma.
